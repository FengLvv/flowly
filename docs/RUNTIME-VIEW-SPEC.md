# Runtime view of Paseo conversations

## Scope and entry

User-approved 2026-11-16: Runtime is an additional view of all native Paseo conversations on this host, including those with no Flowly card. One conversation is one card; never aggregate sessions by task/workspace. Keep project boards and business stages unchanged. Create or bind no Flowly resources for this view.

Runtime is a fixed desktop tab before project tabs and a row in the compact project chooser. Runtime participates in the existing app-run return memory: leaving Flowly and returning restores the last Runtime/project view. Explicit card/workspace/idea links take precedence. Cold start (fresh client bundle) still opens the first project; the entry choice itself stays in app-run memory. The view preferences below persist separately. This replaces the previous task-card runtime proposal and plans/global-kanban.md. User-requested 2026-11-17: add the search, range and sort controls below. Other enhancements (lane-width settings, statistics, timers, density, Git/context/todo displays, AI titles and bulk actions) remain excluded.
